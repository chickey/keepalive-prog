Install it

  1. Unplug the Keep Alive, and unplug anything from its own USB socket.
  2. Hold down the BOOT button and plug the Keep Alive into this computer. Keep holding for a second, then let go. It's now waiting for new firmware.
  3. Click Connect and pick the device in the list. It has a generic name such as USB Module; if the list is empty, see Trouble connecting.
  4. Click Install firmware and leave it plugged in until this page says it's done (usually under half a minute).

Works in Chrome, Edge or Opera on a desktop computer. Your saved presets are normally kept.

Connected

This chip's flash is locked (read-protected). Unlocking erases it completely, including saved presets. After unlocking, unplug the Keep Alive, hold BOOT, plug it in again and click Connect.

Trouble connecting

The device list is empty

The Keep Alive only shows up while it's in update mode. Unplug it, then hold BOOT before plugging it in and keep holding for a second. If it still doesn't appear, try another cable: some USB cables only carry power.

Windows: “couldn't open the device”

Windows needs the generic WinUSB driver for the update mode. This is a one-time step per computer:

  1. Put the Keep Alive in update mode (hold BOOT while plugging it in).
  2. Download and run Zadig.
  3. Choose Options → List All Devices, then pick the device with USB ID 4348 55E0 (often called USB Module).
  4. Set the driver on the right to WinUSB and click Replace Driver (or Install Driver).
  5. Unplug the Keep Alive, return here and start again from step 1.

If you've used WCH's own flashing tools, their driver will have claimed the device; Zadig replaces it. WCH's tools then need their driver back, which you can reinstall from WCH's site.

Linux: “couldn't open the device”

Your user needs permission to open the device. Add a udev rule, then unplug and replug the Keep Alive:

echo 'SUBSYSTEM=="usb", ATTRS{idVendor}=="4348", ATTRS{idProduct}=="55e0", MODE="0666"' | sudo tee /etc/udev/rules.d/50-wch-isp.rules
sudo udevadm control --reload-rules

macOS

No driver is needed. Close any other program that might be using the device, such as WCH's flashing tools.
