Update your Keep Alive

  1. Plug the Keep Alive into this computer as normal. If the config page is open in another tab, click Disconnect there first.
  2. Click Restart into update mode. The first time, Chrome asks which serial port is the Keep Alive: choose Eplop Keep Alive.
  3. A device list opens. When the Keep Alive appears in it, as an unknown device from QinHeng Electronics (the maker of its chip), pick it and click Connect.
  4. Check the details, then click Install firmware.

Works in Chrome, Edge or Opera on a desktop computer. Your saved presets and settings are kept.

First install, or a Keep Alive that won't start
  1. Unplug the Keep Alive, and unplug anything from its own USB socket.
  2. Click Connect. A device list opens; it's empty for now.
  3. Hold down the BOOT button and plug the Keep Alive in. Keep holding for a second, then let go.
  4. Straight away, pick the unknown device from QinHeng Electronics and click Connect. It only waits a few seconds; if it vanishes from the list, unplug it and try again.
  5. Check the details, then click Install firmware.

Trouble connecting

The device list is empty, or it appears and vanishes

The Keep Alive only shows up while it's in update mode, and it leaves update mode after a few seconds if nothing talks to it, so pick it as soon as it appears. If Restart into update mode can't reach it, use First install with the BOOT button instead. If it doesn't appear at all, try another cable: some USB cables only carry power.

Windows: “couldn't open the device”

Windows needs the generic WinUSB driver for the update mode. This is a one-time step per computer:

  1. Put the Keep Alive in update mode (hold BOOT while plugging it in).
  2. Download and run Zadig.
  3. Choose Options → List All Devices, then pick the device with USB ID 4348 55E0 or 1A86 55E0 (often called USB Module).
  4. Set the driver on the right to WinUSB and click Replace Driver (or Install Driver).
  5. Unplug the Keep Alive, return here and start again from step 1.

If you've used WCH's own flashing tools, their driver will have claimed the device; Zadig replaces it. WCH's tools then need their driver back, which you can reinstall from WCH's site.

Linux: “couldn't open the device”

Your user needs permission to open the device. Add a udev rule, then unplug and replug the Keep Alive:

printf '%s\n' 'SUBSYSTEM=="usb", ATTRS{idVendor}=="4348", ATTRS{idProduct}=="55e0", MODE="0666"' 'SUBSYSTEM=="usb", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="55e0", MODE="0666"' | sudo tee /etc/udev/rules.d/50-wch-isp.rules
sudo udevadm control --reload-rules

macOS

No driver is needed. Close any other program that might be using the device, such as WCH's flashing tools.
